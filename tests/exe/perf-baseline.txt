# Recorded performance fingerprints, read by tests/run-exe-tests.py under
# --perf.  These are deterministic under SIS, so a change in the timing model
# moves them.  They are reported, never gated: SIS timing work is expected to
# shift them, and the diff is the signal.  Format:
#
#   <board> <exe> <label> <value>
#
# Captured with the default build, from the reference executables rebuilt
# at RTEMS bc73eb7217, and after the trap entry jitter was decorrelated
# from the simulated time.  Re-bless by
# running ./waf test-run --perf and copying the current values here.

# tmonetoone: cost of one task to task hand off per synchronisation primitive
# (lower is faster), gr740.
gr740 tmonetoone.exe yield 32766
gr740 tmonetoone.exe event 17602
gr740 tmonetoone.exe self-contained binary semaphore 17633
gr740 tmonetoone.exe Classic binary semaphore (FIFO) 16962
gr740 tmonetoone.exe Classic binary semaphore (priority) 16372

gr740_smp smpatomic01.exe 2 617923
gr740_smp smpatomic01.exe 3 617891

# GR740 emulation

In GR740 mode, SIS emulates a limited subset of the GR740 quad-core LEON4
system as defined in the GR740 datasheet. The emulated system includes only
standard peripherals such as APBUART, GPTIMER, IRQMP, GRETH, SRCTRL, GRCLKGATE,
GRSPW2 with the SpaceWire router, and GR1553B. The emulated system includes 16
Mbyte ROM and 64 Mbyte RAM. The SPARC emulation supports an FPU but not the
LEON3 MMU.

To start sis in GR740 mode, use the -gr740 switch.

## GR740 peripherals

The following IP cores from GRLIB are emulated in GR740 mode:

| IP Core   | Address    | Interrupt |
|-----------|------------|-----------|
| L2CACHE   | 0xF0000000 | \-        |
| APBMAST   | 0xFF900000 | \-        |
| APBUART   | 0xFF900000 | 3         |
| IRQMP     | 0xFF904000 | \-        |
| GPTIMER   | 0xFF908000 | 1, 2      |
| GRETH     | 0xFF940000 | 6         |
| GRSPW2    | 0xFF90D000 | 20        |
| GRSPW2    | 0xFF90E000 | 21        |
| GRSPW2    | 0xFF90F000 | 22        |
| GRSPW2    | 0xFF910000 | 23        |
| SPWROUTER | 0xFF880000 | \-        |
| GRCLKGATE | 0xFFA04000 | \-        |
| GR1553B   | 0xFFA05000 | 26        |
| MEMSCRUB  | 0xFFE01000 | 28        |

## SpaceWire emulation

The SpaceWire router carries traffic between the AMBA ports of the four GRSPW2
cores, using the routing table programmed by software. Both path addressing and
logical addressing with header deletion are supported. The router also
distributes SpaceWire interrupt codes between the AMBA ports, gated by the
router wide enable and the per-port direction bits. The eight SpaceWire cable
ports accept configuration and report a running link, but carry no traffic: no
link layer, time codes or RMAP are emulated.

Each GRSPW2 core reports the capability fields of the GR740: an RMAP target,
RMAP CRC, unaligned receive, distributed interrupts, one port and four DMA
channels. The emulation is narrower than the reported capabilities. All four
DMA channels receive, filter on their address pair and transmit, but the RMAP
target is not emulated; a guest that leaves RMAP disabled sees no difference. A
received packet longer than the configured maximum length is cut short and
reported as truncated.

The router reports version 1.2.0 and instance identifier 1. On real hardware
the instance identifier is set by bootstrap signals.

## MIL-STD-1553B emulation

The GR1553B core emulates the bus controller and remote terminal engines. The
bus monitor is not emulated. A single peer terminal is present on the emulated
bus, selected from the engine software enables:

| Enabled engine | Emulated peer |
|----|----|
| Bus controller | A remote terminal at address 4 which serves subaddress 2 with the contents of subaddress 3 incremented by one. |
| Remote terminal | A bus controller which every 50 ms reads two words from subaddress 2 and writes them back to subaddress 3. |

The peer exists so that the GRLIB MIL-STD-1553B example applications can run
without a second terminal on the bus. It is not configurable.

The clock gating unit is a register file only. The emulated cores are always
clocked, so enabling or resetting a clock changes nothing beyond the value read
back.

## Memory scrubber emulation

The MEMSCRUB core emulates the scrub and regenerate runs over the primary and
secondary address ranges, the run position, the global and scrub scoped error
counters with their interrupt thresholds, and the task completed interrupt.

Initialize mode is not emulated. On real hardware the bootloader runs it before
the operating system starts, so no driver reaches it. A run started in that
mode completes immediately.

The emulation does not observe errors on the emulated bus. Errors come from an
injection table which the simulated program fills through two registers that
have no counterpart on the hardware:

| Address | Register |
|----|----|
| 0xFFE01080 | Address at which to inject an error |
| 0xFFE01084 | Write 1 to inject a correctable error at that address, 2 to inject an uncorrectable one, or 0 to discard all injected errors |

A correctable error leaves the table when the scrubber corrects it, matching a
single event upset that a scrub run repairs. An uncorrectable error stays in
the table, matching a hard fault that every pass finds again. The table holds
16 errors, and injecting beyond that replaces the oldest entry.

## Memory interface

The following memory areas are valid for GR740:

| Address                 | Type             |
|-------------------------|------------------|
| 0x00000000 - 0x04000000 | RAM (64 Mbyte)   |
| 0xC0000000 - 0xC1000000 | ROM (16 Mbyte)   |
| 0xF0000000 - 0xF0100000 | L2 cache         |
| 0xFF880000 - 0xFF882000 | SpaceWire router |
| 0xFF900000 - 0xFFA00000 | APB bus 1        |
| 0xFFA00000 - 0xFFB00000 | APB bus 2        |
| 0xFFE00000 - 0xFFF00000 | Memory scrubber  |
| 0xFFFFF000 - 0xFFFFFFFF | AHB plug&play    |

Access to non-existing memory will result in a memory exception trap.

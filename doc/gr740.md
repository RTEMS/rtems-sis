# GR740 emulation

In GR740 mode, SIS emulates a limited subset of the GR740 quad-core LEON4
system as defined in the GR740 datasheet. The emulated system includes only
standard peripherals such as APBUART, GPTIMER, IRQMP, GRETH, SRCTRL, GRCLKGATE
and GR1553B. The emulated system includes 16 Mbyte ROM and 64 Mbyte RAM. The
SPARC emulation supports an FPU but not the LEON3 MMU.

To start sis in GR740 mode, use the -gr740 switch.

## GR740 peripherals

The following IP cores from GRLIB are emulated in GR740 mode:

| IP Core   | Address    | Interrupt |
|-----------|------------|-----------|
| L2CACHE   | 0xF0000000 | \-        |
| APBMAST   | 0xFF900000 | \-        |
| APBUART   | 0xFF900000 | 3         |
| IRQMP     | 0xFF904000 | \-        |
| GPTIMER   | 0xFF908000 | 1, 2      |
| GRETH     | 0xFF940000 | 6         |
| GRCLKGATE | 0xFFA04000 | \-        |
| GR1553B   | 0xFFA05000 | 26        |

## MIL-STD-1553B emulation

The GR1553B core emulates the bus controller and remote terminal engines. The
bus monitor is not emulated. A single peer terminal is present on the emulated
bus, selected from the engine software enables:

| Enabled engine | Emulated peer |
|----|----|
| Bus controller | A remote terminal at address 4 which serves subaddress 2 with the contents of subaddress 3 incremented by one. |
| Remote terminal | A bus controller which every 50 ms reads two words from subaddress 2 and writes them back to subaddress 3. |

The peer exists so that the GRLIB MIL-STD-1553B example applications can run
without a second terminal on the bus. It is not configurable.

The clock gating unit is a register file only. The emulated cores are always
clocked, so enabling or resetting a clock changes nothing beyond the value read
back.

## Memory interface

The following memory areas are valid for GR740:

| Address                 | Type             |
|-------------------------|------------------|
| 0x00000000 - 0x04000000 | RAM (64 Mbyte)   |
| 0xC0000000 - 0xC1000000 | ROM (16 Mbyte)   |
| 0xF0000000 - 0xF0100000 | L2 cache         |
| 0xFF900000 - 0xFFA00000 | APB bus 1        |
| 0xFFA00000 - 0xFFB00000 | APB bus 2        |
| 0xFFFFF000 - 0xFFFFFFFF | AHB plug&play    |

Access to non-existing memory will result in a memory exception trap.
